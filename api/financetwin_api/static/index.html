              3. Aprender del sesgo
              
    
                El sesgo típico es la mediana de
                (previsto − real) / previsto en cada mes.
                Con ≥3 periodos del mismo indicador puede ejecutarse la
                previsualización de calibración
                (calibrado = valor × (1 − sesgo_mediano)).
